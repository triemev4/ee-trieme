# Decisões técnicas e de método

Este índice resume as razões das regras referenciadas pelos guias. Os procedimentos operacionais permanecem nos arquivos indicados, que são a fonte de verdade.

## Hierarquia dos materiais

O guia de [Estruturação Estratégica](../../skills/estruturacao-estrategica/SKILL.md) define a precedência entre base comum, esqueleto da semana, guia da etapa e padrões. Moldes e referências visuais apoiam a apresentação; a evidência e o conteúdo vêm do projeto em andamento. Essa separação reduz conflito entre forma reutilizável e fatos de cada cliente.

## Evidência e decisões

As regras transversais em [base-de-todo-encontro.md](../../skills/estruturacao-estrategica/base-de-todo-encontro.md) e o [método PSE](../../padrao/metodo-pse.md) mantêm a trilha entre fonte, achado, decisão e execução. Fato, estimativa e premissa são rotulados conforme seu estado; lacunas ficam visíveis até uma verificação resolver a incerteza.

## Contrato e aceite

A matriz contratual é a autoridade para escopo e entregáveis. Os fluxos de passagem de venda e encerramento registram divergências e pendências para evitar que uma referência de pacote seja tratada como promessa contratada. A landing page mantém aprovação vinculada à revisão efetivamente conferida, conforme [seu guia](../../skills/landing-page/SKILL.md).

## Privacidade e isolamento

O [instalador](../../skills/instalar/SKILL.md) cria materiais na pasta de trabalho do consultor. Arquivos, credenciais e dados de cada cliente não pertencem ao plugin. Os exemplos públicos são fictícios e não devem ser usados como evidência; informações de um projeto não migram para outro.

## Apresentação

Os [padrões visuais](../../padrao/sistema-visual.md) e [moldes](../../moldes/README.md) mantêm uma forma consistente e validável. Referências visuais neutras informam composição e comportamento, enquanto texto, números, provas e decisões são produzidos a partir das fontes autorizadas de cada projeto.
